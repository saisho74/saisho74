## Projects

### 出席管理システム

職業訓練で学んだC言語とSQLiteを、実際の課題に結び付けるために始めた第1弾の個人開発です。C言語版を学習版として、Python、HTML、CSS、JavaScript、SQLiteを使用したWeb版を主な公開作品として開発しています。

開発時間は、初期設定・環境構築を除き、約100時間です（概算）。

入力検証、データの整合性、安全な更新・削除、同時編集への対応、個人情報を含まない公開方法、工程ごとのテストを重視しています。

> 個人学習・ポートフォリオ用のプロジェクトです。実在する受講生情報や運用データは公開しません。

#### 今後の構想

今後は、表計算ソフトなどで作成した受講生データの一括登録、複数の受講生を対象とした一括出欠入力、CSVファイル（表形式のデータをやり取りするファイル）によるデータの取込み・出力を追加し、入力作業を効率化することを検討しています。

また、過去の出欠履歴を保持したまま、日々の出欠入力が不要となった受講生を入力対象から外し、必要に応じて対象へ戻せる管理機能も検討しています。

また、NFC／FeliCaなどのICカード、指紋認証、センサー、マイコンと連携し、出欠登録の自動化やIoT（機器をネットワークにつないで情報を収集・活用する仕組み）への発展も構想しています。

現在のクラス・利用者・日付・状態を管理する仕組みは、必要な機能を追加することで、学校・研修機関の出欠管理、企業の勤怠管理（出退勤管理）、その他の管理システムへ応用できると考えています。

ただし、企業の勤怠管理には、出退勤時刻、休憩、残業、休暇、承認、利用権限、法令への対応などが必要です。現在のシステムをそのまま企業で利用できるわけではなく、これらは現時点では未実装の将来構想です。

### Pet Monitor Pro

> コンセプト：テクノロジーで、家族であるペットの健康と幸せを見守る。
